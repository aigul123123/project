# Random Password Generator

## Автор
Вафина Айгуль

## Описание
Данное приложение представляет собой генератор случайных паролей с графическим интерфейсом.

Функционал:
- Генерация пароля заданной длины
- Выбор типов символов (цифры, буквы, спецсимволы)
- Отображение истории сгенерированных паролей
- Сохранение истории в JSON файл
- Загрузка истории при запуске программы

## Используемые технологии
- Python
- Tkinter (GUI)
- random
- json
